# План E08 — игры (T51, T07, T45, T11)

Спецификация — `docs/superpowers/specs/2026-10-19-games.md`. Шаги по 2–5 минут, у каждого — файлы и
проверка. Машина медленная: Java проверяется одним прогоном трёх классов, веб — точечным vitest.

## Ядро

1. Красные тесты T51 и T07 — `server/src/test/java/dev/mikki/stream/DurakTest.java`,
   `GameVisualEventsTest.java`; заглушки `Durak.AUTO_TAKE_MS`, `DurakSeat.auto`.
   Проверка: `-Dtest='DurakTest,DurakPauseTest,GameVisualEventsTest'` — падают ровно новые (6).
2. `Durak.transfer`: предел = рука нового защитника; событие `transfer`. Проверка: тест T51.
3. `unbeaten()`/`roomToThrow()` в `validateAttack` и `canThrow`. Проверка: тест пустой руки.
4. `cornered()` (паросочетание + перевод), срок `AUTO_TAKE_MS` в `reschedule`, `take(..., cornered)`
   в `tick`. Проверка: три теста «нечем отбиться».
5. `nothingToThrow()`, `auto()` в снимке, `pass` только при `canThrow`. Проверка: тест метки.
6. `OpenApiConfig`: `DurakSeat.auto` (необязательное, nullable, `pass|take`), `transfer` в
   `GameVisualEvent.type`. Проверка: `fmt:check` и тот же прогон — зелёный.

   (перегенерация — в общей волне). Проверка: `tsc -b`.

   доступ к общему `AudioContext`. Проверка: `core/sounds.test.ts`, `core/preferences.test.ts`.

   Kenney из `public/sounds/games/`, синтез на замену. Проверка: `core/game-sounds.test.ts`.
10. `ui/useGameSounds.ts` — хуки для четырёх столов; подключение в `PokerTable`, `DurakTable`,
    `ChessTable`, `GarticTable`. Проверка: `tsc -b`.
11. `ui/Settings.tsx` `SoundFields` — ползунок «Громкость сигналов и игр» и флажки «Звуки игр».
    Проверка: `ui/Settings.test.tsx`.
