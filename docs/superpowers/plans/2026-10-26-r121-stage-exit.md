# Выход из интеграции к участникам и возврат «чёлкой» — план (R121)

> **Для исполнителя:** superpowers:executing-plans (один агент, без субагентов — правило владельца). Шаги — `- [ ]`.

**Цель:** у каждого зрителя — личный выход из интеграции на сцене к виду «все участники» и возврат в одно касание
чёлкой сверху по центру; интеграция идёт для всех, кинозал не перезагружается и не теряет синхронность.

**Архитектура:** чистая модель вида (`core/stage-view.ts`) + стор встречи `stageAway`; `Stage` отдаёт слой
интеграции и вид людей соседями, слой ушедшего не размонтируется, а прячется `visibility: hidden` в том же узле;
чёлка (`StageNotch`) и кнопка «Участники» (`StageExitButton`) читают ту же модель.

**Стек:** React 19, Base UI kit, Vitest + Testing Library, Playwright против стенда, CSS на токенах.

**Спека:** `docs/superpowers/specs/2026-10-26-r121-stage-exit-design.md`.

## Общие ограничения

- Ключ i18n — сразу в 8 локалях (`i18n/locales/*.json`), `i18n/coverage.test.ts`; кириллица в коде — храповик
  `scripts/i18n/check.mjs` (обновить базу `--update`, если строки ушли в локали).
- CSS только на токенах (`--stage-glass`, `--stage-glass-blur`, `--stage-glint-1`, `--shadow-2`, `--radius-3`,
  `--text-sm`, `--motion-base`, `--ease-emphasized`); hex/rgb/`!important` нельзя.
- Пороги — из `ui/breakpoints.ts` (`SHEET` 767, `ROOMY` 960); `breakpoints.test.ts` сверяет числа в CSS.
- Проверки: только точечные `npx vitest run <файлы>`, `npx prettier --check <файлы>`, `npx tsc -b` один раз в конце.
- Коммиты по-русски, маленькие, `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Ядро, `gateway`-протокол и клиент Windows не меняются.

## Внимание при проверке

1. Ушедший жмёт пробел/K/F (плеер) или F/C/R/A (покер) — ничего не происходит у комнаты.
2. Во время ухода комната включает следующую серию / ставит паузу — у ушедшего тот же `<video>`, звук идёт, чёлка
   показывает новое название/паузу; ушедший не выдёргивается обратно.
3. Ушёл из каталога (без фильма), а комната включила фильм — фильм открывается у ушедшего (как у всех).
4. Интеграция кончилась у ушедшего — чёлка исчезает, остаётся обычная встреча, `stageAway` сброшен (новая
   интеграция той же породы потом откроется у всех).
5. Телефон 390/667×375 с открытым листом — чёлка не под листом и не перекрывает лица; на 667×375 у листа больше
   места, чем в интеграции.

### Задача 1: модель вида

**Файлы:** создать `web/src/core/stage-view.ts`, `web/src/core/stage-view.test.ts`.

**Интерфейсы (производит):**
```ts
export type StageKind = 'chess' | 'gartic' | 'poker' | 'durak' | 'cinema';
export interface StageOccupant { kind: StageKind; film: boolean }
export function stageOccupant(snapshot: Pick<Snapshot, 'chess'|'gartic'|'poker'|'durak'|'watch'>, catalog: boolean): StageOccupant | null;
export type StageView = 'meeting' | 'integration' | 'people';
export function stageView(occupant: StageOccupant | null, away: StageKind | null, viewing: boolean): StageView;
export function awayAfter(away: StageKind | null, before: StageOccupant | null, after: StageOccupant | null): StageKind | null;
```

- [ ] Тесты: порядок сцены (шахматы > рисование > покер > дурак > кинозал; фильм — `film: true`, только каталог —
  `film: false`); `stageView`: нет сцены → `meeting`; ушёл от этой → `people`; `viewing` при сцене → `people`;
  иначе `integration`; `awayAfter`: та же сцена → тот же уход; кончилась/другая → `null`; каталог → фильм → `null`;
  фильм → другой фильм (оба `film`) → уход остаётся; фильм → только каталог → уход остаётся.
- [ ] Красный → реализация → зелёный (`npx vitest run src/core/stage-view.test.ts`), коммит.

### Задача 2: встреча — `stageAway` и переходы

**Файлы:** `web/src/core/meeting.ts`, тест `web/src/core/meeting-stage.test.ts` (новый).

**Производит:** `readonly stageAway: Store<StageKind | null>`, `stageOccupant(): StageOccupant | null`,
`leaveStage(): void`, `returnToStage(): void`.

- [ ] Тесты (фальшивые `api/media` как в `meeting.test.ts`): `leaveStage` при покере → `stageAway='poker'`, без
  сцены — ничего; `returnToStage` → `null` и закрытый просмотр экрана (`view.close`), закрепление не снято;
  снимок без покера → `stageAway=null`; `openStream` при кинозале → `stageAway='cinema'`; `openCinema('youtube')`
  при уходе → `null`.
- [ ] Реализация: приватный `settleStage()` после `snapshot.set` в `accept` и после `cinema.set` в `openCinema`/`end`
  (`awayAfter` с прошлым `stageOccupant`); каталог считается, если `knownProvider(cinema)`.
- [ ] Зелёный, коммит.

- [ ] Тест: кинозал → `leaveStage` → тот же узел `video.watch-video` (`toBe`), слой `data-away`, сетка

- [ ] Ушёл — `exitFullscreenWithin(слой)`. Зелёный + старые `stage-cinema`, `stage-pin`, `stage-paused`. Коммит.

**Файлы:** `ui/notch-state.ts` (чистая подпись), `ui/notch-state.test.ts`, `ui/StageNotch.tsx`, `ui/stage-notch.css`,

**Производит:** `notchState(t, snapshot, me, nowMs): { kind; name; status; turn: boolean; ring?: {actionAt; deadline}; paused?: boolean; live?: boolean }`;

- [ ] Тесты подписей: «Покер · 3 за столом»; ход у меня → `status:'Ваш ход'`, `turn`, `ring`; пауза стола — без

  тик позиции раз в секунду. Локали `stage.notch.*` ×8.
