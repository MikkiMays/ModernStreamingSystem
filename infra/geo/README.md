# Базы адресов службы аналитики

Служба `insight` (R239, `docs/architecture/analytics-v2.md` §4.4) берёт из адреса запроса страну, номер сети
провайдера (ASN) и класс сети — и больше ничего: сам адрес не хранится ни в базе, ни в журнале (Р-139). Для этого ей
нужны локальные базы. Они лежат вне репозитория, в каталоге установки `.local/geo` (переменная `GEO_DIR`), и
подключены в контейнер только для чтения как `/geo`.

**Без баз служба работает**: страна и сеть — «неизвестно», признак VPN не ставится, склейка по отпечатку опирается
только на отпечаток подсети.

## Файлы

| Файл | Что это | Источник | Лицензия |
| --- | --- | --- | --- |
| `dbip-country-lite.mmdb` | адрес → страна | [DB-IP Lite](https://db-ip.com/db/lite.php), `dbip-country-lite-ГГГГ-ММ.mmdb.gz` | CC BY 4.0 |
| `dbip-asn-lite.mmdb` | адрес → ASN | DB-IP Lite, `dbip-asn-lite-ГГГГ-ММ.mmdb.gz` | CC BY 4.0 |
| `hosting-asn.txt` | ASN дата-центров и выходов VPN → класс сети `hosting` | [`brianhama/bad-asn-list`](https://github.com/brianhama/bad-asn-list), `bad-asn-list.csv` | MIT |
| `mobile-asn.txt` | ASN мобильных операторов → класс сети `mobile` | `infra/geo/mobile-asn.txt` этого репозитория (держатели сверены по RIPEstat) | своё |

Лицензия DB-IP требует указывать источник там, где данные показаны: в пульте, рядом со странами и провайдерами, —
строка «IP Geolocation by DB-IP» со ссылкой на `https://db-ip.com`.

Списки ASN — текст: строка `AS12345` или `12345`, после пробела — что угодно, `#` — комментарий. Своих строк в
`.local/geo/hosting-asn.txt` не держать: обновление заменяет файл целиком. Список мобильных операторов правится в
репозитории — `infra/geo/mobile-asn.txt`.

## Класс сети

- `hosting` — ASN есть в `hosting-asn.txt`: дата-центр или выход VPN. Сессия человека из такой сети получает
  признак «VPN или прокси — вероятно»; на личность это не влияет (кука и профиль от адреса не зависят).
- `mobile` — ASN есть в `mobile-asn.txt`. Список короткий и приблизительный: оператор, у которого под одним номером
  и домашний, и мобильный интернет, в него не входит.
- `home` — ASN известен и не входит ни в один список.
- `unknown` — базы ASN нет или адрес в ней не найден.

## Обновление

```bash
bash infra/geo/update.sh               # скачать сейчас в .local/geo (или в GEO_DIR)
sudo bash infra/geo/update.sh install  # таймер systemd cord-geo.timer: 3-го и 17-го числа, 04:40
docker compose exec insight /cord-insight geo 8.8.8.8   # что базы говорят об адресе
```

Служба раз в минуту смотрит на время изменения файлов и перечитывает их сама — перезапуск не нужен. Файл заменяется
переименованием, поэтому наполовину записанным служба его не видит. Не скачалось — прежний файл остаётся, скрипт
выходит с кодом 1 и строкой в `/var/log/cord-geo.log`.

Пояса часов по странам (для признака «пояс браузера не встречается в стране адреса») вшиты в службу:
`rust/insight/data/zones.tab` — два столбца `zone1970.tab` из tzdata (общественное достояние).
