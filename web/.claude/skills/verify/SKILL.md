# Проверка Cord вживую

Тесты здесь ничего не доказывают: их гоняет CI. Доказательство — работающее
приложение и то, что оно показало.

## Куда идти

**Стенд `https://meet.nikg.tech` — первый выбор.** Это та же машина: ядро, SFU и
службы подняты `docker compose` из `/opt/meet/ModernStreamingSystem`. Медиа
поднимается по-настоящему, встреча доживает до «В эфире», кинозал играет.
Проверять надо **выкаченную** сборку: страница «О программе» печатает
`Cord <версия> · <коммит>` — сверьте с `git rev-parse --short HEAD`.

**Dev-сервер нужен только для невыкаченных правок интерфейса.** Ядро отвечает
403 на чужой `Origin` (`RequestGuard` сравнивает с `PUBLIC_URL`), поэтому
`npm run dev` напрямую получает 403 на `/api/v1/session`. Обход — крошечный
http-прокси на node, подставляющий `origin`/`host` боевого адреса, и
`CORD_DEV_API` / `CORD_DEV_SERVICES` на него. Но **встреча там живёт 20 секунд**:
SFU (`rtc.nikg.tech`) из этого окружения недоступен, и комната честно
показывает «Соединение не восстановилось». Значит, dev-сервером проверяют
прихожую, настройки, витрины — всё, что рисуется сразу; кинозал и музыку — нет.

## Как запускать браузер

Playwright с chromium уже установлен в `web/`. Конфиг кладите **внутрь `web/`**
(из скретчпада не резолвится `@playwright/test`), каталог потом убирайте:

```ts
// web/.verify/config.ts
use: { baseURL: 'https://meet.nikg.tech',
       launchOptions: { args: ['--use-fake-device-for-media-stream', '--use-fake-ui-for-media-stream'] } }
```

Запуск: `cd web && npx playwright test --config .verify/config.ts .verify/<файл>.spec.ts`.

## Дорога до встречи

```ts
await page.goto('/');
// Подключение происходит само: ждать надо «Новую встречу», а не жать «Подключиться» —
// кнопка исчезает сама, и клик по ней повиснет до таймаута.
await expect(page.getByRole('button', { name: /Новая встреча/ })).toBeVisible({ timeout: 25000 });
await page.getByRole('button', { name: /Новая встреча/ }).click();
await page.getByLabel('Ваше имя').fill('Проверка');
await page.getByRole('button', { name: 'Начать встречу' }).click();
await expect(page.getByText('В эфире', { exact: true })).toBeVisible({ timeout: 40000 });
```

## Ловушки, на которых уходит время

- **Карточку интеграции ищите по заголовку, а не по тексту.** У занятой группы
  подпись «Сейчас активна другая интеграция — Музыка» содержит чужое имя, и
  `hasText: 'Музыка'` попадёт в «Кинозал»:
  `page.locator('.service-group').filter({ has: page.locator('b', { hasText: /^Музыка$/ }) })`.
- **На телефоне интеграций в нижней панели нет** — они за «Настройки и действия»
  (там же «Завершить для всех» и «Настройки встречи»).
- **Каталог кинозала не открывает ролик по Enter**: надо нажать «Смотреть
  вместе», и обязательно `click({ force: true })` — прозрачная кнопка
  «Подробнее» на всю карточку перехватывает нажатие.
- **Пульт плеера засыпает за 2,8 с** и выключает `pointer-events`. Перед каждым
  нажатием — `page.locator('.watch-theater').hover()`.
- **`locator('.watch-video').tap()` бьёт в середину кадра**, где лежит
  центральная кнопка паузы. Чтобы проверить нажатие по самому кадру, целиться
  координатой: `page.touchscreen.tap(box.x + box.width * 0.25, box.y + box.height * 0.72)`.
- **Состояние видео читать у элемента**, а не по кнопкам:
  `.watch-video` → `{ paused, ended, currentTime, duration }`.

## Что можно посмотреть мимо браузера

- Сроки хранения и прочие настройки ядра: запасной экземпляр без порта и уборки —
  `docker compose run --rm --no-deps -e SERVER_PORT=8099 -e STREAM_SCHEDULING_ENABLED=false -e SAVED_ROOM_RETENTION=<значение> core`.
  Непонятную строку он не проглатывает: `APPLICATION FAILED TO START` + причина.
  Вывод обязательно перенаправлять в файл: `timeout` убивает конвейер вместе с
  буфером `grep`.
- Комнаты и избранное: `docker compose exec -T postgres psql -U streaming -d streaming -c "..."`.
- Журнал служб: `docker compose logs services --since 5m`.

## Чего не ждать

- **Комната с музыкальным ботом не закрывается,** пока бот занимает место, а
  бот не уходит из опустевшей комнаты с пустой очередью (его цикл ждёт события
  издателя или смены ревизии, а watcher пишет `save(changed=False)`).
  Освободить место — `docker compose restart services`, после чего комната
  закрывается и удаляется.
- **Перезапуск SFU не даёт «потери соединения»:** Go-издатель сам ретраит
  подключение и не сообщает Python о закрытии.
