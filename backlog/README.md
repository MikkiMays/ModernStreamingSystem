# Бэклог Cord

Бэклог лежит в репозитории ядра и едет вместе с ним на любую машину. Пути считаются от
**`$CORD_ROOT`** — каталога, где рядом лежат обе репы (`ModernStreamingSystem` и
`ModernStreamingSystem.Windows`).

## Текущая волна — релиз 1.1 (с 31.10.2026)

`release-1.1/` — 17 задач владельца от 31.10.2026 (R143–R159), разбор каждой по коду и план релизов
1.1.x. Начинать с `release-1.1/STATUS.md`, затем `release-1.1/PLAN.md`; формулировки владельца —
дословно в `release-1.1/TASKS.md`.

## Как запускать сессию

```bash
ModernStreamingSystem/backlog/bin/run.sh master    # tmux cord-master: текущая волна из этого файла
# отключиться: Ctrl-b d;  вернуться: tmux attach -t cord-master
```

Автопилот без человека — `tmux new -s cord-autopilot ModernStreamingSystem/backlog/bin/autopilot.sh`
(волна — `CORD_WAVE`, по умолчанию `release-1.1`; останавливается, когда в волне появился `FINAL.md`).

## Правила, которые не меняются

- Параллельно работает другая сессия, в том числе в общем рабочем каталоге: сливать только в своём
  worktree от свежего `origin/main`, пуш fast-forward, ничего чужого не терять (`PROTOCOL.md` §0).
- Одновременно — не больше двух агентов-субагентов (владелец, 31.10.2026).
- Модель — Opus; простое — можно Sonnet.
