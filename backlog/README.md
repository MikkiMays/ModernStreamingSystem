## Новый сервер

```bash
git clone <адрес репозитория ModernStreamingSystem>   # репу Windows рядом положит setup-server.sh
ModernStreamingSystem/backlog/bin/setup-server.sh                  # инструменты, репа Windows, плагины
claude            # один раз: /login, затем /mcp → figma и context7 → войти в браузере
```

Эта машина станет **продом** `meet.nikg.tech`: первым делом после изучения системы агент
переносит туда прод (эпик E17). Для этого положи рядом `.env` и `youtube_cookies.txt` со
старого сервера, дай дамп базы или доступ к старому серверу и переключи DNS, когда агент
скажет (`OWNER-ACTIONS.md` → «Перед запуском на новом сервере»).

## Как запускать

Одна общая сессия в авто-режиме — она сама идёт по волнам и эпикам:

```bash
ModernStreamingSystem/backlog/bin/run.sh master   # tmux-сессия cord-master: Opus 5.5, xhigh, auto
# отключиться: Ctrl-b d;  вернуться: tmux attach -t cord-master
```

Упёрлась в лимит или закрылась — `bin/run.sh resume master` (вернуться в неё же) или
`bin/run.sh master` (новая, продолжит по `STATUS.md`). Если хочется, чтобы перезапуск после
лимитов шёл сам, без тебя, — вместо этого `tmux new -s cord-autopilot
ModernStreamingSystem/backlog/bin/autopilot.sh`.

## Модель, усилие, режим

| Что | По умолчанию | Почему |
| --- | --- | --- |
| Модель | `opus[1m]` — Opus 5.5 с контекстом 1M (`CORD_MODEL`) | Самая сильная модель; длинной сессии большой контекст нужен, чтобы реже сжиматься. Если `[1m]` недоступен на плане — `opus` |
| Усилие | `xhigh` (`CORD_EFFORT`) | На весь бэклог сразу: глубоко, но лимиты плана Max тратятся медленнее, чем на `max`, и сессия успевает больше между паузами. `max` даёт прирост на трудных решениях, но на десятках эпиков подряд съедает лимит раньше |
| Режим | `auto` (`CORD_PERMISSIONS`) | Без подтверждений там, где действие безопасно и разрешено; выкатку владелец разрешил заранее. `bypassPermissions` под root Claude Code не принимает |

**Режим планирования не нужен.** Plan mode останавливает работу до одобрения плана человеком,
а здесь планирование встроено в каждый эпик (`PROTOCOL.md`: разведка → решения → план в
`docs/superpowers/plans/`), и решения агент принимает сам по `DECISIONS.md`.

  После установки: `claude` → `/mcp` → `figma` → войти в аккаунт Figma в браузере; создать файл
  для экранов Cord и положить ссылку в `OWNER-ACTIONS.md`. Нужен E15 (экраны в Figma) и
  полезен E16 (дизайн-система). Без него оба эпика работают на HTML-макетах и скриншотах.
- **context7** — тоже `/mcp` → войти (документация библиотек без устаревших API).
- Своих скиллов агент наделает сам (`.claude/skills/` в репе); ставить заранее не нужно.
