сессии; агент переносит ответ в `DECISIONS.md` → «Решено владельцем».

## Перед запуском на новом сервере

`README.md` → «Новый сервер» — команды по порядку. Только владелец может:

- **Войти в Claude Code** (`claude`, затем `/login`, аккаунт с планом Max) и в GitHub
  (`gh auth login` или токен с доступом к обеим приватным репам, правами `contents`,
  `actions`, `workflows`; для релиза Windows — ещё запись релизов).
- **Новый сервер — прод (решено 18.10.2026).** Для переезда (E17) владелец даёт:
  `.env` и `youtube_cookies.txt` со старого сервера (положить в `ModernStreamingSystem/`, в git
  их нет и не будет); дамп PostgreSQL старого прода или SSH-доступ к старому серверу —
  иначе старт с чистой базой и избранное людей пропадёт; переключение DNS `meet.nikg.tech` на
  новый IP (или доступ к DNS).
- **Режим без подтверждений.** Под root Claude Code отказывается работать с
  `bypassPermissions`. Нужен либо отдельный пользователь (в группе `docker`), либо режим
  `auto` (по умолчанию в `bin/run.sh`).

## Действия, которые агент не может сделать сам

- **Figma (E15, E16; T57):** подключить MCP-сервер Figma и авторизовать его (OAuth в
  браузере) — `README.md` → «Что подключить». Создать файл «Cord» и дать ссылку. Если MCP не
  умеет рисовать на холсте, агент напишет плагин Figma — его нужно будет один раз запустить в
  этом файле (Plugins → Development → Import plugin from manifest). Без доступа E15 готовит всё
  к импорту и не стоит.
- **Telegram (E09):** BotFather — описание бота, картинка «что умеет бот», Mini App и домен
  (`/newapp`, `/setdomain`), если Bot API это не позволяет сделать запросом.
- **Мобильные приложения (E12), если E12 решит, что без нативной оболочки нельзя:** Apple
  Developer Program ($99/год), Google Play Console ($25 разово).
- **Подпись Windows-установщика / Electron (E01):** сертификат издателя (или Azure Trusted
  Signing). Без него SmartScreen остаётся (это уже так) — для «продукта» это первое, что
  видит человек, поэтому стоит сделать к выпуску Electron-клиента.
- **Платные сервисы:** любые — только с его «да» (E10, E11).
