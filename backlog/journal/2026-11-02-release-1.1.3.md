# Выпуск 1.1.3 — журнал (01–02.11.2026)

Задачи владельца R168–R182 (`release-1.1.3/TASKS.md`, дословно; R182 добавлена посреди волны). Работали четыре
агента по два одновременно — «Доска», «Кинозал», «Звук», «Ошибки» (Opus) — и главная сессия (пульт, тосты,
автоподключение, недавние, дурак, игры, светлая тема звонка). Тесты — в конце (память «dev-first-test-at-end»).

## Что вошло

- **Доска (R168, R169, R174, R176, R175 а/б, агент, Р-65…Р-69).** Курсор соседа — только стрелка цвета участника
  своим слоем; мини-карта на месте «?»; маркер и стикер в колонке инструментов (на телефоне — «Ещё
  инструменты»), стикер — инструмент с набором текста; ссылка — только на сайт или почту, в новой вкладке, адрес
  без схемы дописывается до https (ядро иначе молча роняло его у соседей); у ушедшего от доски она не
  просвечивает; окно «Сохранить доску в чат?» по важности. Главная сессия: непереведённые строки Excalidraw —
  на языке человека (`gaps.ts`), «Добавить в библиотеку» убрано, `Dialog` набора больше не раздвигается
  подвалом.
- **Кинозал (R172, агент, Р-60…Р-63).** Стенд во Франкфурте: ivi отдаёт бесплатное только в Россию — теперь
  отказ сразу, понятно и со страной сервера. Поток ivi — плеерным API площадки без yt-dlp, отказы её причиной.
  Разбор больше не держит общий пул и полосы комнаты, уход и смена видео снимают работу сразу (поиск музыки после
  зависшей ivi — сразу, было `429 PLATFORM_BUSY`). Буфер «как у YouTube»: вперёд 20–30 с по каналу, позади 30 с,
  файл — кусками по 2 МБ (скачано вперёд 64 → 22 с, докачка на паузе 8,8 → 0 МБ). ivi на этом стенде — после
  выхода через Россию (`OWNER-ACTIONS.md` п. 13). Журнал агента — `2026-11-02-r172-ivi.md`.
- **Звук (R182, агент, Р-75).** Шум у вошедшего посреди музыки — растяжение NetEq, догонявшего запас 600 мс
  первые ~6 с, и ускорение при спуске цели. Начало стерео-дорожки придерживается трансформом приёмника и
  уходит декодеру пачкой; запас музыки вниз не шагает. Запись того, что слышит слушатель: THD+N первых 2 с
  −12…−16 → −44…−48 дБ, темп 0,90–0,93 → 1,000. Двойного проигрывания нет; кодек и голос — без изменений
  (замеры показали, что поднимать нечего без потерь в устойчивости).
- **Ошибки (R180, агент, Р-80…Р-83).** Одна точка перевода ошибок для человека (`core/failure.ts`), технику —
  в журнал браузера, «Недавние ошибки» поддержки и счётчик `cord_client_errors_total{place,code}` (ручка
  `POST /api/v1/client-errors`, кардинальность ограничена с обеих сторон). Плашка «Сеть не пропускает звонок» —
  без «порта 443» и «TURN», с «Подробнее» в «Диагностику». 69 мест веба, 11 текстов ядра, ~15 мест служб.
  Журнал агента — `2026-11-02-r180-errors.md`.
- **Главная сессия.** «Камера» из «…» пульта убрана (R170); «Ссылка скопирована» — 2,5 с и по часам: Base UI
  замораживал срок, пока окно не в фокусе (R171); автоподключение снова с микрофоном и «?» у переключателя
  (R173, Р-57); слов действия на карточке недавних нет (R177); «Сесть за стол» — сразу, без «Сохраняем ход…», а
  любая команда ждёт один снимок комнаты вместо двух (R178, Р-59); первый бой — всегда пять карт, настройки нет
  (R179); шапка дурака и покера до правого края, зрители справа под ней (R181); светлая тема звонка целиком —
  поле, пульт, меню, медиа тёмной карточкой (R175 в, Р-58); «← Интеграции» по краю карточек (R175 д).
