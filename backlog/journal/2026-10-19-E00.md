## Шаг 4. Инструменты (`backlog/bin/`, `web/scripts/`)

- `ci-status.sh [ветка] [N]` — последние прогоны CI обеих реп; через `gh` (после `gh auth login` владельца)
  или токен из окружения. Ещё не прогнан: доступа к GitHub у агента нет (`OWNER-ACTIONS.md`).
- `active-meetings.sh` — живые встречи по базе ядра (люди без ботов, JOINING/CONNECTED/RECOVERING).
  Прогон: «Стек Cord не поднят (postgres не запущен) — встреч нет.», выход 0.
- `deploy.sh <службы>` — встречи → `flock .deploy.lock` → `build` (с `CORD_BUILD`) → `up -d --no-deps` →
  ожидание health → проверка, что коммит HEAD вшит в бандл gateway. Без `down`/`-v`.
- `.github/workflows/verify.yml`: `paths-ignore: backlog/**`, `continue-on-error` у загрузок артефактов,
  печать `.local/logs` браузерного стенда при падении. То же для `verify-deployed.yml`.
- `web/scripts/shots.mjs` — снимки экранов (home, download, prejoin, settings по вкладкам, meeting) на
  ширинах × темах + `report.json` с переполнением. В git (а не в `.local/`, который потерялся со старым
  сервером вместе с `stack.sh`, `poker-shots.mjs`, `durak-six.mjs`, `recorded/`).

## Точки входа, которых не хватало эпикам (сверено с кодом)

- **E02:** у браузерной главной **нет левой колонки** (избранное в модалке) — T46 в вебе означает новую
  колонку; правая панель встречи — `useState(360)`, ширина не сохраняется. `startedAt` в снимке нет, есть
  `everConnected` (три перехода в CONNECTED). Счётчик «только вы» `MeetingView.tsx:318` считает ботов.
  «В эфире» ждут 36 мест в 17 файлах e2e (включая помощник `e2e/support/cinema.ts`).
- **E03:** у ползунка нет своего `:focus` — выделение даёт глобальное `:focus-visible` (`styles.css:97-105`).
- **E05:** `max-participants` ограничен `@Max(10)` в `StreamProperties.java:27`; бот занимает место
  (`RoomService.java:243-245`, тест `RoomServiceTest.java:261-286`); комната с одним ботом не
  закрывается (`Lifecycle.java:299-311`). Профиль устройства в create/join не передаётся вовсе — для T52
  нужен новый заголовок и `Member.profileHash`. `capabilities` отдаёт зашитые 720/1080/1440 и 15/30/60, веб
  их не читает. T49: громкость бота применяется после `play()` (`Stage.tsx:101-116`) и по умолчанию 1.
  T38: `Meeting.listen` не пропускает бота и озвучивает rejoin как выход+вход.
- **E06:** правило прав в 4+ местах; `DELETE music` — `owner=True` (`app.py:202`), тест закрепил баг
  (`test_services.py:260-263`); веб показывает «Убрать сервис» только ведущему (`Services.tsx:388-398`).
- **E07:** «По ссылке» — история **на устройстве** (`preferences.cinemaLinks`, 10 записей); серверный
  `cinema_links` — общий кэш без комнаты, удалять там нельзя. Курсор в плеере уже прячется, клавиш нет.
  Рекламные метки HLS не обрабатываются, но доходят до плеера; у ссылок `season/episode` не читаются.
- **E08:** вероятная причина T51 — `Durak.java:886` (предел после перевода `attacks + hand`); `DurakYou`
  уже содержит `plays`; метки «нечего подкинуть» нет. Загрузки игр — заглушки `Stage.tsx:386-424`.
- **E09:** Mini App/`web_app`/`initData`/`startapp`/`callback_query` и флага `TELEGRAM_WEBAPP_ENABLED` нет.
  `/new` в личке бота без проверки — спам комнатами (и для E11).
- **E10:** своих метрик и логов в ядре нет; actuator только на 127.0.0.1.
- **E11:** лимиты только поминутные по IP/ключу/профилю; подписанные ссылки кинозала не привязаны к
  комнате (5 ч), потолка трафика нет; `X-Service-Secret` = `X-Internal-Secret`.
- **E14:** ~1200 литералов + ~240 текстовых узлов JSX по-русски в 149 файлах, 4 самодельных склонения.
- **E16:** 387 hex-цветов, 38 радиусов, 40 теней, 71 размер шрифта, 26 z-index, 25 `!important`; SVG-марки
  нет; `index.html` без цвета фона (белая вспышка).
- **E01:** Windows CI проверяет клиент против `meet.nikg.tech` (`verify-service.ps1`) — зависит от старого
  прода; `ReleaseClient` первым спрашивает приватный GitHub (404).
