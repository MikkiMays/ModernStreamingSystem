## Как устроено (коротко)

- Старт: `app.whenReady` → `SplashWindow.run(CordUpdater)` → `runSplash` (чистая машина состояний) →
  `MainWindow.showLoading()` (T55) → `router.prepareBootstrap(origin)` → `loadURL(origin)`.
- Безопасность: `sandbox`, `contextIsolation`, без Node; `will-navigate`/`will-redirect`/`setWindowOpenHandler`
  → только origin серверов (каталог + текущий), внешняя https — `shell.openExternal`; разрешения — только
  media/display-capture/notifications/fullscreen/clipboard для origin сервера; загрузки — с origin или `blob:`;
  `certificate-error` → отказ; `cord-app://` — строгий CSP; fuses в `electron-builder.yml`.
- Мост: `send` → `readPageMessage` (≤ 16 КиБ, схема как `BridgeProtocol.Read`) → `Shell.onMessage`;
  `invoke` — `update.status`, `capture.sources`, `session.renew` (отдаёт `token: null`: пароль держит сама
  страница, флаг `session` не объявлен — В-2); `on` — `hotkey`, `hotkeys.status`, `navigate`, `settings.open`,
  `deeplink`, `thumbar`, `update.status`, `notification.action` и прочие из ADR §3.3.
- Обновление: `NsisUpdater` + `SignedGenericProvider` (`latest.yml` + `latest.yml.sig`, ключи из
  `build/update-keys.json`, адреса только внутри канала) → sha512 (electron-updater) → sha256 из подписанного
  манифеста → `quitAndInstall(true, true)`; `settings.expectedVersion` ловит отказ установщика.
- Захват: `setDisplayMediaRequestHandler` отдаёт источник только после выбора человеком — либо
  `capture.select` от веба (своё окно E16, 10 с), либо окно оболочки `picker.html` (экраны/окна с
  миниатюрами, «Со звуком системы» = Electron `loopback`, только Windows). Звук отдельного приложения
  (`capture.app-audio`) ждёт `cord-native` — флаг не объявлен.
- Клавиши: `globalShortcut` по правилам `MicrophoneHotkey.TryNative` (Ctrl/Alt обязательны, без Win и F12),
  строки состояния как в WinUI; `ptt` с фазой «отпустил» ждёт `cord-native` (Raw Input).

## Шаги владельца

- Создать боевой ключ Ed25519 (`node -e` из `scripts/sign-manifest.mjs` или `openssl genpkey -algorithm ed25519`),
  положить закрытый в секрет `CORD_UPDATE_SIGN_KEY`, публичный — в `desktop/build/update-keys.json`
  (`keys[0]`; ключ стенда сейчас там, закрытая половина — `/opt/ModernStreamingSystem/.local/cord-update-key.pem`).
- Переменная `CORD_UPDATE_CHANNEL` (боевое зеркало) и `publish: generic url` в `electron-builder.yml`.
- Сертификат Authenticode (`CORD_SIGN_PFX_BASE64`/`CORD_SIGN_PASSWORD`) — как и раньше, без него SmartScreen.

## Осталось (по важности)

1. `cord-native` (Rust/napi-rs): process loopback (звук приложения / «кроме Cord»), Raw Input (push-to-talk с
   отпусканием, мышь), монитор переднего окна для оверлея, DPAPI не нужен (В-2).
2. Веб: своё окно выбора источника по E16 через `capture.sources`/`capture.select` (сейчас — окно оболочки),
   переключатели «мягкого взаимодействия» в настройках (E03), переключатель оверлея и клавиша `overlay.toggle`.
3. Каталог: `contracts/server-catalog.v1.schema.json`, `contracts/catalog-keys.json`, `GET /api/v1/catalog`
   в ядре и `scripts/sign-catalog.mjs`; клиент уже умеет проверять JWS (`catalog.ts`) и читает снимок
   `src/shell/catalog.json`; круглые SVG-флаги — набор с лицензией (сейчас полосные для 12 стран, остальным — код).
4. `metrics.json` в CI (размер, память, старт, fps), видео e2e на раннере, запись в ADR §10.
5. `session.renew` через оболочку, если владелец захочет хранить пароль сервера в клиенте (сейчас — страница).
6. Вывод WinUI из обращения (`windows.yml`, `src/Cord.*`) после приёмки — п. 11 эпика.
