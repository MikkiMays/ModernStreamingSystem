## Как снималось

- `web/scripts/dom-svg.mjs` (новое): страница → SVG со слоями. Группы с понятными именами («кнопка «Новая встреча»»),
  фон и рамки (радиусы по углам, рамки внутренней тенью — так их рисует набор E16), тени — фильтром в записи Figma
  (импорт даёт эффект «тень»), линейные и радиальные градиенты, обрезка `overflow`, повёрнутые элементы — матрицей
  вокруг `transform-origin` (меряются без поворота), значки SVG — путями с вычисленными цветами, флажки/переключатели
  родные — нарисованы, картинки/видео/холсты — data-URL, SVG-картинки — векторами (Node подставляет файл), текст —
  строками, как их разложил браузер; что импорт теряет (начертание, межбуквенный), записано меткой `⟦…⟧` в имени.
  Там же `auditPage()` — аудит чёткости на каждом кадре.
- `figma-screens.mjs --svg --toggle-theme`: тот же PNG E15-A + SVG + аудит в `manifest.json`; вторая тема — атрибутом
  без перезагрузки (вдвое меньше контекстов); рецепты E15-B: окна Electron (`file://…/desktop/src/shell` с подставным
  `cordShell`), Mini App (параметры запуска в hash и мост WebView, ответ службы подставлен), главная в Electron (мост v2),
  язык, iPhone/Android (User-Agent, `navigator.standalone`), сценарий `meeting-b` (выбор площадки, музыка, чат: файл-
  программа и переход по ссылке, «Свернуть в окно», подсказки о фоне, Mini App во встрече, Telegram у создателя).
  Невыкаченное на стенд (знакомство, помощь, /support, английский и китайский, раздел «Windows», «Активность») —
  dev-сервером ветки (`stand-proxy.mjs`, `vite.figma.config.mjs`).
- Выгрузка: `figma-cards.mjs` (карточки, шапки, обложка — HTML → SVG), `figma-plan.mjs` (файлы страницы по порядку),
  `upload_assets` → `figma-svg-upload.mjs` (адреса берёт из ответа инструмента, исправляет `stroke-opacity`, которую
  импорт теряет), `figma-layers.js` (начертания, абзацы, привязка цветов к переменным темы кадра — 12 537 привязок
  только на «Настройках»), `figma-place.js` (раскладка). Переменные — `figma-tokens.js`, значки — `figma-icons.mjs`.
- Описания — каталог `screens-catalog.mjs` (115 состояний: что это, кто и откуда, правила, задачи, компоненты,

## Что заблокировано и почему

- **Предел вызовов Figma MCP на Starter** кончился в самом конце: не удалось прочитать узлы рядов карт 3–4 для
  `docs/screens.md` (там ссылки ведут на страницы) и сделать последний визуальный обход. REST с personal-токеном на
  тяжёлых запросах отвечает 429.
- **Starter:** три страницы на файл (→ четыре файла, E15-B-1), одна мода у коллекции переменных (→ две коллекции
  тем, E15-B-3), нет публикации библиотеки (→ компоненты только в «карте 1», E15-B-4). Code Connect не делался
  (не просили; на Starter недоступен).
- **Кадры — слои SVG с привязанными переменными, но не экземпляры компонентов.** Подменять группы импорта
  экземплярами набора без потери вида — отдельная работа; компоненты набора и экраны живут рядом.
- **Не сняты:** «встреча завершится в …» (`endsAt` не удалось подставить в снимок встречи), окно выбора источника в
  вебе клиента (E01-B2 на стенде нет, медиа через dev-сервер не поднимается), поиск и плеер музыки (бот держит комнату
  на стенде), игровые листы, установщик и уведомление Android — ряды с описанием там, где экран есть в продукте.
- Создание встреч на стенде ограничено антиботом (10 в час с адреса, общий для всех агентов на машине) — сценарии
  переписаны на одну встречу (E15-B-6).
