## Решения по умолчанию

- Окно настроек **фиксированного размера** на настольных ширинах (как у Discord: почти весь
  экран или крупный фиксированный лист). Слева — шапка профиля устройства (имя, аватар,
  «изменить»), поиск по настройкам и разделы с иконками в группах (набросок — в
  `refs/README.md` → «Для Cord (E03, T26)»), справа — содержимое со своей прокруткой. Переключение раздела не меняет размеров окна. На телефоне — список
  разделов → экран раздела с «назад».
- «Голос и видео» по образцу FACEIT: устройство, проверка уровня микрофона живым индикатором,
  громкость ввода и вывода, обработка, качество камеры и показа (варианты из E05: без «Авто»,
  до 1080p60).
- T31: выделение при нажатии на ползунок — фокус-кольцо от мыши. Кольцо остаётся **только для
  клавиатуры** (`:focus-visible`), при нажатии мышью и касании его нет. Так во всех ползунках
  (громкость собеседников, музыка, кинозал, игры). Скриншоты «до» (с выделением) и «после» —
  в `screens/E03/slider/`, ссылка в отчёте владельцу: он просил «показать скрином».
- «О программе» — без ссылок на GitHub и исходники, без «сервер отстаёт — `./update.sh`»
  (T56, сделано в E01-B0 — не вернуть обратно).
- Раздел «Серверы» (если остаётся в настройках) — только выбор из каталога с флагами (П4),
  без поля адреса.
- Переключатели «мягкого взаимодействия с Windows» из E01-B (T53) — в разделе приложения,
  видны только в клиенте.
- T33: раздел «Аккаунты» — строки сервисов (Яндекс Музыка, Telegram — SOON до E09, остальное
  по E06-B): иконка, имя, состояние, кнопка «Подключить» / «Подключено» / «Сбросить».
- T29: убрать пояснения, которые повторяют подпись или объясняют очевидное. Короткая подсказка
  — только там, где без неё ошибаются; длинное — в «?» с поповером. Каждое удаление —
  строкой в спецификации («было → стало»).
- T27: в вебе в разделе клавиш — строка «В браузере сочетания работают, только пока вкладка
  Cord активна. В приложении — всегда.» Модель сочетаний общая для веба и клиента (E01 делает
  глобальный перехват). Конфликты (пробел у плеера — E07) проверяются при назначении.

## Шаги

1. Разведка по `PROTOCOL.md`, скриншоты каждого раздела «до» на 7 ширинах.
2. Каркас окна на примитивах E16, перенос разделов, тема в «Оформление».
3. «Голос и видео», «Аккаунты», «Клавиши».
4. Чистка описаний (T29) и ползунки (T31) по всему приложению, а не только в настройках.
5. e2e `settings-accounts.spec.ts`, `return-and-settings.spec.ts` — обновить; новый сценарий:
   размеры окна одинаковы на всех разделах (замер `getBoundingClientRect`).

## Проверка

Одинаковый размер окна на всех разделах на каждой ширине; ни одного горизонтального
переполнения; мост `settings.open` из Windows открывает нужный раздел; скриншоты.
