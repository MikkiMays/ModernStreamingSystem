# E14 — Языки

Этап A (слой переводов) — волна 1, **до** переделки экранов: каждый новый экран сразу пишется
через переводы. Этап B (переводы, установщик, бот) — волна 5, когда тексты устоялись.

## Задача владельца

T03 «Язык системы, добавить французский, итальянский, английский, китайский, испанский и
еще может пару популярных, как на веб, так и на клиент при установке»

Языки — П9 (`DECISIONS.md`): ru (исходный), en, es, fr, it, zh-Hans, de, pt-BR.

## Что уже есть

Слоя переводов нет: строки по-русски прямо в разметке веба, в сообщениях ядра (`Problem`
отдаёт русский текст), в службе (`HTTPException(409, "Во встрече открыт кинозал…")`), в
Telegram-боте (`COMMANDS`), в XAML и C# Windows-клиента, в установщике Inno Setup (русский).
Окончания по числу («3 участника») местами собираются вручную — проверить `primitives.tsx`,
`GamesGroup.tsx`.

## Этап A — слой

1. Выбрать библиотеку по context7 и бандлу: i18next+react-i18next, Lingui, FormatJS — с
   ICU-плюралами (у русского четыре формы), ленивой загрузкой языков, типизацией ключей,
   извлечением строк. Решение — в `DECISIONS.md`.
2. Ошибки ядра и службы — **коды** (`problem.type`/`code` + параметры), текст собирает
   клиент. Старый русский `detail` остаётся для совместимости.
3. Вынести все строки веба в каталог `ru`, скриптом и проверкой: CI падает на кириллице в
   `.tsx` вне каталога, кроме разрешённых мест.
4. Выбор языка: веб — язык браузера, потом настройки; формат дат, чисел и времени — `Intl`.

**Готово:** приложение на `ru` выглядит как раньше (скриншоты совпадают); в `.tsx` ни одной
русской строки интерфейса вне каталога; e2e зелёные.

## Этап B — переводы и платформы

1. Переводы всех каталогов на 7 языков с глоссарием (встреча, комната, ведущий, демонстрация,
   интеграция, кинозал — одни слова везде). Длинные языки (de, fr) — проверка вёрстки на 320 и
   390. Китайский — шрифт с CJK, без своих файлов на 20 МБ, если можно системными.
2. Клиент Windows (Electron из E01): язык выбирается в установщике (у выбранного в E01
   установщика — свой механизм; у NSIS и Inno Setup китайский есть, проверить лицензию файлов
   сообщений), передаётся приложению и странице; меняется в настройках. Описание установщика
   (T54, П15) — на всех языках, без единой ссылки.
3. Telegram-бот: `setMyCommands` и `setMyDescription` с `language_code` для каждого языка,
   ответы — по языку пользователя.
4. Тексты, которые нельзя переводить машинно без проверки (юридические, о программе), — с
   пометкой «нужна вычитка» в `OWNER-ACTIONS.md`.

**Готово:** скриншоты ключевых экранов на каждом языке на 390 и 1440 без обрезанных
подписей; установщик с выбором языка из CI; бот отвечает по-английски англоязычному клиенту.
