## Направление облика

Discord — главный референс (X9): окно поверх приглушённого фона, дерево разделов слева, контейнеры-строки без
«скрыть/раскрыть», тонкие полосы прокрутки, сегмент SD/HD, переключатели. Телемост — в отдельных вещах: страницы
настроек, которые помещаются в окно без прокрутки (R101), превью камеры в разделе «Видео» (R100), мини-оверлей звонка на
рабочем столе (R93), одно главное действие в окне показа (R60). Cord делает «подобным образом и лучше» за счёт трёх вещей,
которых нет ни у того, ни у другого:

1. **Глубина светом, не рамками.** Поверхности `--surface-1..3` с тенями `--shadow-1..3` и верхней внутренней подсветкой
   в тёмной теме. Единственная линия — волосок `--hairline` между строками. Discord рисует рамки, Телемост — серые
   карточки на сером; у Cord карточка читается тенью и светом.
2. **Один акцент — синий Cord; цвет интеграций — только у интеграций.** Бренды площадок и игр (R33) красят плашку значка
   (витрина, аккаунты, чипы игр), но никогда — кнопки приложения. В плеере музыки цвет площадки — только у знака
   источника 16 px (R128): вкладки, игла, громкость и ⏯ монохромные. Так интеграции видны сразу, а интерфейс остаётся
   спокойным.
3. **Движение отвечает на действие, а не украшает.** Три длительности (120/200/320 мс), две кривые входа/выхода, только
   `transform` и `opacity`. Единственная «витринная» анимация — кольцо говорящего и эквалайзер мини-плеера, потому что
   они показывают звук, а не настроение.

Типографика: Inter Variable, шкала 12/13/14/16/20/24/32, веса 400/500/600; заголовок окна 20/600, заголовок группы
20/600 с `-0.01em`, подпись строки 14/500, пояснение 13/400 `--muted`. Цифры всегда `tabular-nums`. Заглавных подписей
и «айбрау» нет (исключение «В ЭФИРЕ» — метка, не подпись); одно место на предвходе («НОВАЯ ВСТРЕЧА» на r103-34) убираем.

Сетка и плотность: шаг 4 px (`--space-*`), высоты элементов 32/36/40 (`--control-sm/md/lg`), строка настроек 56 px,
радиусы 8 (элементы) / 12 (карточки и меню) / 16 (окна и плитки) / 20 (листы на телефоне). Мобильный порог — 767 px,
планшет — 1199 px, низкое окно — `max-height: 720px`.

Тон текстов (ux-copy): глагол в кнопке («Присоединиться», «Показать», «Сбросить»), подпись называет вещь, пояснение
есть только там, где без него человек ошибётся или потеряет звук/доступ (S7). «Это можно поменять потом», «советуем»,
повторы подписи — убираем. Все тексты ниже — русские образцы; ключи меняются во всех восьми локалях одним коммитом (X1).

### Правило «помещается без прокрутки» (R101)

Эталон — окно 1180×820: контент 764 px высотой. Бюджеты страниц при колонке 760:

| Раздел | Высота контента | Как уложено |
| --- | --- | --- |
| Звук | 24 + Микрофон 356 + 16 + Динамики 196 + 24 = 616 | две карточки |
| Видео | 24 + Камера 420 + 16 + Показ 300 + 24 = 764 | камера — сетка 2 колонки на ≥1024: превью 400×250 слева, четыре строки справа; показ — пять строк, из них две парные (качество + частота в одной строке) |
| Оформление, Звуки, Сервер, Аккаунты | ≤ 400 | одна карточка |
| Горячие клавиши, Windows/Оверлей | > 764 | группы с разделителями и прокруткой — это списки, им прокрутка положена |

При окне ниже эталона (ноутбук 1366×768 → окно 720 высотой) прокрутка появляется только у «Видео», и это допустимо:
правило R101 — для эталона и выше; в низких окнах превью камеры сжимается до `max-height: 200px` (`@media (max-height: 760px)`),
и «Видео» снова помещается в 668 px.

### Подсветка раздела при прокрутке (R12, R115)

Только для страниц с группами. Активный якорь = группа, пересекающая линию `scrollTop + clientHeight/3`; если
`scrollTop + clientHeight ≥ scrollHeight − 2` — **последний якорь**, даже если его группа короткая; у самого верха
(`scrollTop ≤ 2`) — первый. Если прокручивать нечего (`scrollHeight − clientHeight ≤ 2`) — подсвечен **выбранный
щелчком** (или первый), геометрия его не меняет (R115). После перехода по якорю `measure` не считает до `scrollend`. Рейка активного якоря едет `transform: translateY` 200 мс `--ease-standard`.

### Полосы прокрутки (R17, S2)

Токены (обе темы): `--scrollbar-size: 12px` (зона), бегунок 4 px в покое и 6 px при наведении на область,
`--scrollbar-thumb: color-mix(in srgb, var(--text) 22%, transparent)`, `--scrollbar-thumb-hover: 40%`. Правило глобальное:

```css
*::-webkit-scrollbar { width: var(--scrollbar-size); height: var(--scrollbar-size); }
*::-webkit-scrollbar-track, *::-webkit-scrollbar-corner { background: transparent; }
*::-webkit-scrollbar-button { display: none; }
*::-webkit-scrollbar-thumb { border: 4px solid transparent; border-radius: var(--radius-full);
  background: var(--scrollbar-thumb) padding-box; }
*:hover::-webkit-scrollbar-thumb { border-width: 3px; }
*::-webkit-scrollbar-thumb:hover { background-color: var(--scrollbar-thumb-hover); }
@supports not selector(::-webkit-scrollbar) { * { scrollbar-width: thin; scrollbar-color: var(--scrollbar-thumb) transparent; } }
```

В Chromium 121+ свойства `scrollbar-*` отключают `::-webkit-scrollbar`, поэтому они живут только под `@supports not`.
«По Discord» бегунок прозрачен, пока курсор не над областью: `.settings-nav`, `.settings-content`, `.home-nav__scroll`,
`.panel-body` получают `--scrollbar-thumb: transparent` и возвращают цвет на `:hover` и на 800 мс после `scroll`
(`data-scrolling`). Электрон — тот же Chromium, вид одинаковый.

### Segmented (R78, R95, S4)

Сегмент — радиогруппа «как SD/HD в Discord»: контейнер `--surface-2`, высота 32 (`sm`) / 36 (`md`), радиус 8,
внутренний отступ 2; пункты — радиус 6, 13/500 `--text-secondary`, выбранный — `--surface-1` + `--shadow-1` в светлой,
`--surface-3` в тёмной, текст `--text` 600. Индикатор — один псевдоэлемент, едущий `transform: translateX`/`width`
200 мс `--ease-emphasized` (позиция и ширина — CSS-переменные `--seg-x/--seg-w`, которые ставит компонент по
`offsetLeft/offsetWidth` выбранного). Недоступный пункт (выше потолка сервера) — `--text-disabled`, `title`
«Этот сервер допускает до 1080p · 60 fps». Клавиатура: стрелки ←/→ переключают, Home/End — крайние; кольцо фокуса —
вокруг контейнера, только в режиме клавиатуры. Касание — высота 44.

Где: Видео (720 / 1080 / 1440 и 30 / 60; Чёткость / Плавность), окно показа (то же), зум камеры 0.5× / 1× / 2×, «Кто
может войти», шумоподавление, тема, положение оверлея, размер аватара.

## Фокус

Задачи: R26, R11, R23, R75; решение S1. Доступность: WCAG 2.4.7 — кольцо есть у каждого элемента управления, когда
человек идёт с клавиатуры.

**Правило модальности ввода.** `ui/input-modality.ts` ставит `html[data-input="pointer" | "keyboard"]`:

- `pointerdown` (capture) → `pointer`;
- `keydown` → `keyboard`, только если клавиша из набора Tab, ←↑→↓, Home, End, PageUp, PageDown, F6 и не зажаты
  Ctrl/Alt/Meta. Shift разрешён (Shift+Tab, Shift+стрелки — навигация);
- **не переключают**: одиночные Shift, Ctrl, Alt, Meta; любые сочетания (Ctrl+Shift+M, оверлей); Esc, Enter, Space,
  буквы и цифры; Alt+Tab и возврат окна. Начальное значение — `pointer`.

**Кольцо.** Один токен `--focus-outline: 2px solid var(--accent)`, `--focus-offset: 2px`; для элементов внутри тёмных
поверхностей и на сцене — `--focus-offset-inset: -2px` (кольцо внутрь, чтобы не резалось `overflow`). На сцене
(`.media-stage`) кольцо `--palette-blue-300` — на чёрном синий 400 даёт 3,6:1, 300 — 6,2:1.

```css
:root:not([data-input='keyboard']) { --focus-outline: 0 solid transparent; }
:where(button, a, input, select, textarea, [tabindex]:not([tabindex='-1'])):focus-visible {
  outline: var(--focus-outline); outline-offset: var(--focus-offset); }
:where([tabindex='-1'], [role='dialog'], [role='alertdialog'], [role='menu'], .modal):focus-visible { outline: none; }
```

**Окна и меню — никогда.** Контейнеры с `tabindex=-1` (попапы Base UI, `.settings-window`, старый `.modal`) кольца не
получают ни в каком режиме. Начальный фокус окна — заголовок (`h2 tabindex=-1`), не крестик: крестик остаётся
первым в Tab-порядке, но мышью открытое окно его не подсвечивает.

**Пункт меню.** `.ui-menu__item:focus-visible { outline: none }`. Состояние показывает `data-highlighted`:
фон `--surface-hover`, текст `--text`. В режиме клавиатуры подсвеченный пункт дополнительно получает
`box-shadow: inset 0 0 0 2px var(--accent)` — видно, где курсор, но окно меню не обводится. Разрушительный пункт —
`--danger`, подсветка `--danger-soft`.

**Запись сочетания (R23/R24).** Кнопка «Изменить» → «Отмена» (Esc) — щелчок по ней отменяет; после отмены фокус
возвращается на кнопку без кольца (режим `pointer`), с клавиатуры — с кольцом.

**Поля ввода** сохраняют свою рамку `--accent` при `:focus-within` в любом режиме — это не кольцо, а состояние поля.

Проверка (e2e Chromium): щелчок → Shift → `outline-style: none` у карточки профиля, окна, крестика, пункта меню;
Tab → `solid` у первого элемента; axe без регрессий.

  круг с тёмным значком), «играть» сдвинут на 1 px вправо; наведение `brightness(1.1)`, нажатие `scale(.96)`.
- **Ход трека** — волосок `--hairline-strong` по низу полосы от скругления до скругления: дорожка `--text` 12 %,
  заливка `--text` 64 %, `transform: scaleX()` (250 мс линейно, под `reduce` — без перехода).
- **Музыка есть, трека нет** — тем же стеклом чип 32: знак ♪ на `--surface-hover` и состояние словами («Музыка ·
  Очередь пуста»), нажатие — виджет.
- **За столом игры** (покер, дурак, шахматы, рисование): у шапки стола есть место `IntegrationBarSlot`
  (`ui/IntegrationBar.tsx`), и слой сцены переносит туда мини-плеер и «Включить музыку» порталом — частью шапки, а не
  плашкой поверх стола. Там полоса без стекла и тени: `--surface-hover`, высота 40, радиус 8, поле 4, обложка 32, ⏮ ⏯ ⏭ по

  кинозал во встрече вместе не бывают (`stageBusy` ядра). Место общее, чтобы следующие соседи шапки (возврат в
  интеграцию, R121) вставали туда же, а не каждая шапка заводила своё; верх сцены по центру оно не занимает.
- **Телефон** (≤ 767): только обложка 36 и ⏯ 36 в полосе 44 над сценой (в шапке стола — 32 и 32 в полосе 40), нажатие на
  обложку — нижний лист (`Drawer`, 85 dvh).

**Виджет** — тот же плеер, что в панели (`MusicWidget`, раздел «Плеер»), в `Popover` 360 (слой 39, `--shadow-3`, появление
200 `--ease-emphasized` `translateY(-6)→0`), заголовок «Музыка» и крестик. На телефоне — нижний лист с ручкой, 85 dvh.

### Выход из интеграции и чёлка (R121)

Владелец 25.10: «внутри сцены нельзя выйти на всех участников… будет сверху как раз челка с активным плеером или
текущей активной интеграцией, на которую можно всегда зайти». Интеграция на сцене (кинозал — фильм и/или свой каталог,
покер, дурак, шахматы, рисование) идёт для всех; каждый зритель может уйти от неё к обычной встрече — та же сетка,
«Говорящий», закрепление, плитки показа со «Смотреть» — и вернуться в одно касание. Выбор личный: стор встречи
`stageAway`, в ядро не уходит ничего, живёт до конца встречи на этом устройстве.

```
         ╭──────────────────────────────────────────────╮     вырез от верхнего края сцены, 40 (телефон 44)
         │ [кадр 56×32] Never Gonna Give You Up · 0:42  │     стекло сцены, радиус 0 0 16 16, --shadow-2
         ╰──────────────────────────────────────────────╯
 ┌───────────────┐ ┌───────────────┐ ┌───────────────┐          ниже — обычная встреча, плитки не накрыты
 │      Майя     │ │     Алекс     │ │  Ника · LIVE  │
```

- **Выход** — «Все участники» (значок `LayoutGrid` 16 — «камеры блоками»; `Users` уже у кнопки списка людей в пульте — + подпись 13/500, кнопка 32, `--surface-2`, волосок `--line`, радиус 8;
  ≤ 700 — только значок) в шапке интеграции: у покера и дурака — рядом с полным экраном (обе про вид), у шахмат и
  рисования — первой после места мини-плеера (`IntegrationBar.tsx`), на пульте плеера — пилюлей перед «Каталогом»
  (`.watch-browse`), в полосе каталога — значком 20. Подсказка «Все участники (G)», `aria-keyshortcuts="G"`. Не
  «Участники»: так уже называется кнопка пульта, открывающая список людей в панели, — два разных действия с одним
  именем путали бы и глаз, и диктора.
- **Чёлка** (`StageNotch`) — пока интеграция идёт, а зритель не в ней (сетка, «Говорящий», чужой экран). Свисает от
  верхнего края сцены, как вырез: в потоке над видом людей, плитки сдвигает, а не накрывает; слой интеграций справа
  опускается под её строку. Одна строка: знак (плашка 24 цвета игры, `--radius-0`, значок 12 — бренд только знаком,
  как у чипов R30 и знака источника R128) или живой кадр фильма 56×32 (радиус 8), имя 13/600 и через «·» состояние
  13/500 `--stage-muted`, `tabular-nums`: «3 за столом» (пустой стол — только имя), время своего плеера (пауза —
  значком ‖, эфир — красная точка и LIVE), «Каталог»; рисование — «Рисует Аня» / «Вы рисуете».
- **«Ваш ход»** — состояние золотом кольца хода (`--gold`, 600) и `TurnRing` вокруг знака от меток ядра; без
  мигания. Шахматы — «Ваш ход» без кольца (у них свои часы).
- **Живой кадр** — тот же `<video>`, что идёт спрятанным, перерисованный в холст 4 раза в секунду (под `reduce` —
  раз в 2 с; скрытая вкладка — не рисует). Второго потока нет.
- **Нажатие** — назад (`scale(.98)` 120 мс), наведение — `--stage-glass-strong`, кольцо фокуса — внутрь.
  Появление — выезд из-под шапки `translateY(-100%)→0` + прозрачность, 200 мс `--ease-emphasized`; под `reduce`
  длительности токенов — 0.
- **Кинозал не перезагружается.** Слой интеграции не размонтируется: ушедшему он прячется в том же узле —
  `visibility: hidden`, `inert`, `aria-hidden`, `position: absolute` во всю сцену до пульта. В Chromium (спайк 26.10)
  ни `visibility`, ни `opacity`, ни `content-visibility`, ни даже `display: none` не ставят `<video>` на паузу; но
  `display: none` обнуляет размер, а сжатие `transform` его уменьшает — и hls.js (`capLevelToPlayerSize`) опустил бы
  качество, а на возврате сбросил буфер. Звук фильма у ушедшего идёт (как у Discord Activity). Столы держатся так же:
  звук хода и тики часов нужны как раз ушедшему, открытый лист, выбранная карта и ползунок ставки не теряются.
  Клавиши спрятанной интеграции молчат (пробел/K/стрелки/M/F плеера, F/C/R/A покера), полный экран внутри неё при
  уходе сворачивается.
- **Клавиша G** без модификаторов, по месту клавиши (в русской раскладке «п»): только когда фокус на сцене или нигде,
  не в поле и не в диалоге; совпавшее сочетание микрофона или оверлея — их.
- **Фокус и диктор.** Ушёл — фокус на чёлке («Вернуться: Покер — Ваш ход»), вернулся — на «Все участники»; строка
  состояния сцены: «Все участники» / «На сцене: Покер».
- **Что открывает интеграцию у ушедшего**: чёлка, G, «Открыть на сцене» в панели «Интеграции» (у идущей игры — под
  её строкой без раскрытия, у кинозала — рядом с «Закрыть просмотр для всех»), выбор площадки каталога. Новая
  интеграция, запущенная кем-то, открывается у всех, как раньше; уход от каталога, пока комната включила фильм, тоже
  забывается. Интеграция кончилась — чёлка уходит, остаётся обычная встреча.
- **Чужой экран и закрепление** при занятой сцене — вид участников: «Вернуться в разговор» ведёт в сетку, чёлка — в
  интеграцию. Мини-плеер музыки у ушедшего от стола — на слое сцены, а не в шапке спрятанного стола.
- **Телефон** (≤ 767): чёлка 44 во всю строку при нужде, вплотную к верху сцены; лист панели опускается на её строку
  (и на строку слоя сцены под ней, если играет музыка). Боком (≤ 767 × ≤ 500) с открытым листом лица разговора уходят,
  как под полосой фильма R120 (люди — во вкладке «Люди»), и лист встаёт сразу под чёлкой. На 667×375 с фильмом и чатом
  листу оставалось 23 px (R120) — ушедшему к участникам 151, фильм звучит, кадр — в чёлке.
- **Клиент Windows.** Шапка встречи — заголовок окна (`--titlebar-h`), чёлка под ней; во весь экран шапки нет, но нет и
  кнопок окна (зона WCO — нули).

### Пульт (R77)

Группы плашек как сейчас. Когда идёт показ экрана, кнопка показа становится **красной с крестиком**: фон `--danger-fill`,

### Плитки: закрепить и открепить (R83, R84)

Меню плитки («…» и ПКМ): **«Закрепить»** → у закреплённой **«Открепить»** (значок `PinOff`), у своей плитки тоже.
Закреплённая плитка: раскладка «сцена» (`spotlight`) — большая плитка на всю ширину, остальные — **лента 96 px снизу**
(плитки 170×96, по центру; справа лента спорила бы со слоем интеграций в правом верхнем углу). В углу закреплённой — значок `Pin` 16 на `--stage-veil-2` (метка, не кнопка) и кнопка

говорящего» — это раскладка «говорящий», и у неё в правом верхнем углу плитки показывается та же метка с подписью
«Говорит». Переход между раскладками — плитки едут `transform` 320 мс `--ease-emphasized` (FLIP), без перескоков.

**Телефон (R84)**: закреплённая/говорящая плитка — на всю ширину сверху, `aspect-ratio: 4/3` (портрет) или `16/9`
(ландшафт), ниже — горизонтальная лента 72×96 с собственной плиткой первой; ленту можно прокрутить; пульт внизу не
перекрывает ленту (у ленты `padding-bottom: calc(var(--dock-h) + 8px)`). Долгое касание плитки — меню с «Закрепить/
Открепить». Кнопка «Открепить» дублируется на большой плитке слева внизу (`IconButton stage` 36) — на телефоне наведения нет.

### Меню камеры (R35, R36)

## Столы игр

### Дурак: стол по высоте и лоток (R129)

Владелец 26.10: «кнопку усадки за стол … по-середине, а также кнопку "бито" … по-середине и сделать более видимой,
иногда бывает съезжает разметка и приходилось пролистывать страницу». Было: стол прокручивался внутри сцены, полоса
зрителей под ним срезала руку, а «Бито»/«Беру» и «Сесть за стол» жили в подвале по краям — на 1280×720 за краем окна.
Стало: **стол не прокручивается ни на какой высоте** и делится сверху вниз — шапка, сукно, лоток (рука и строка
действия). Ужимается сукно, а не кнопка.

```
 ┌ Дурак                ( Ваш ход: отбивайтесь или берите · 24 с )      [♪][≡][⏸][⚙][⊞ Все участники][⤢] ┐  шапка 56
 │            ( Майя )                                                                       ┌──────┐ │
 │  [колода]          [ 7♣ ]                     [бито]                                      │ Ника │ │  сукно —
 │            ( Алекс · вы )                                                                 └──────┘ │  остаток
 │                 ┌── веер руки: карта = ¼ высоты стола, 48…118 px ──┐                         зрители │
 │   Выберите карту или перетащите её на стол  [  ✋ Беру  ]  [✕ Отменить]                      справа │  строка 64
 └──────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

- **Лоток** (`.durak-tray`): полоса руки и строка действия (`.durak-dock`), сетка `1fr auto 1fr`. Главная кнопка —
  ровно по центру под рукой; слева от неё, прижатая к ней, — что делать сейчас одной строкой (отказ хода `--danger`,
  выбранная карта — `--accent`, остальное `--muted`); справа — тихая вторая. Строка есть всегда, даже пустая: появление
  кнопки или подсказки стол не двигает.
- **Главная кнопка — одна на всех режимах** (атака, защита, подкидывание, перевод): у защитника «Беру», у остальных
  «Бито»; смена хода меняет надпись, а не место. Недоступна — **на месте**, контуром `--line-strong` и текстом
  `--text-disabled`; доступна — заливка `--accent-fill`, `--on-accent`, 16/650, высота 48 (`--control-touch`), не уже 176
  (телефон 156, низкий стол 132), радиус 12, нажатие `scale(.98)`. Зрителю на том же месте — «Сесть за стол» (значок
  кресла), ведущему между партиями — «Раздать» (из шапки стола убрана; зрителю-ведущему — тихой второй рядом с «Сесть
  за стол»). Положить, подкинуть и перевести — по-прежнему движением карты на сукно или нажатием цели на нём.
- **Вторая кнопка** (`.durak-aside-act`) — «Отменить» выбор карты: контур `--line`, `--text-secondary`, 44 в высоту; на
  узком лотке — значком 44×44 (имя у диктора).
- **Чей ход** — плашкой посередине шапки, как у покера (`.durak-turn`): ваш ход — `--accent-soft` и рамка акцента;
  уже 980 px стола — своей строкой под названием и кнопками. Отдельной полосы над сукном (46 px) нет.
- **Рука** (`--hand-w`): `clamp(48px, 16.9cqh, 118px)` от высоты стола (телефон — до 84, низкий стол — 40…64).
  Нахлёст карт — от их числа и ширины стола: веер встаёт без прокрутки, пока соседняя закрывает не больше двух третей
  карты, дальше — стрелки. Подписи «Ваша рука · 6 карт» нет: число — у своего места. Руки нет (зритель, ждём раздачи,
  вышел) — полоса схлопнута; карты пришли — раскрывается за 320 мс (`--motion-slow`, под `reduce` — сразу).
- **Сукно**: невысокое (до ~380 px) — имя и роль места сбоку от лица, а не под ним; совсем низкое (до 170) — верхнее и
  своё лицо садятся на край сукна. Трое и больше на широком сукне — середина уже (46 %), колода и отбой мельче,

управление** — чтобы не разворачивать Cord.

нет ни в покое, ни при наведении (владелец 29.10: «тень бесполезная — убрать»).

### Развёрнутый — 260×auto (по «⋯» или двойному щелчку)

Сверху своя плитка 236×132 (камера или аватар), затем список действий 44 px с значками 20 и подписями 14/500:
Микрофон (состояние справа: «выкл.»), Камера, **Показ экрана** (зелёный значок при показе, подпись «Остановить»),
Поднять руку, Участники · счётчик-бейдж, Чат · красный бейдж непрочитанных (R87), Интеграции (музыка/кинозал — подпись
«Играет: Put On»), Настройки звука; внизу — красная кнопка 44 «Выйти из встречи» на всю ширину (`--danger-fill`,
значок трубки). Без «Запись» и «Права» — в Cord их нет. Нажатие «Участники» или «Чат» разворачивает главное окно на
нужной панели. Переход компактный ↔ развёрнутый — `height` через `grid-template-rows` 200 мс `--ease-emphasized`.

### Поведение

Появляется через 400 мс после того, как главное окно потеряло видимость (`blur` + `isMinimized`/перекрыто) в звонке;
исчезает, когда главное окно снова видно. Клики — обычные (это не игровой оверлей; `focusable: false`, чтобы не
забирать фокус у игры при вводе). Говорящий — та же задержка ≤ 150 мс, что у игрового виджета. Тема — `--stage-*`
(всегда тёмная, как плитки). Настройка в «Windows»: `Switch` «Мини-окно звонка, когда Cord свёрнут» (вкл.).

Связь со звуком восстанавливается — сверху полоса «Связь восстанавливается… 18 с» (`--warning`, как шапка встречи),
микрофон, камера и показ погашены и нажатий не шлют (встреча их в это время не исполняет — так же гаснет пульт),
кольца говорящих сняты; «Участники», «Чат», «Настройки» и «Выйти из встречи» работают. Упала страница встречи —
мини-окна нет, страница загружается заново; упало или зависло само мини-окно — создаётся новое с тем же состоянием.

Окно не «замерзает» (R137, 1.0.11). Нажатая кнопка сразу полупрозрачна — ждёт ответа встречи (`mini.ack`), нового
состояния или 4 с, после чего оболочка просит у встречи всё заново. Нажатие просит нужное состояние («выключить»),
а не «переключить». Перестало рисовать кадры (сон, блокировка, смена монитора или масштаба, сброс GPU) — оболочка
сама ставит новое окно с тем же состоянием, не чаще 3 раз за 5 минут. Анимаций появления нет.

## Установщик

### `Segmented`

На `@base-ui/react/radio-group` + `radio`. `role=radiogroup`, пункты `role=radio` с `aria-checked`; стрелки ←/→

| Проп | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `value` / `defaultValue` | `T` | — | выбранное значение |
| `onValueChange` | `(v: T) => void` | — | |
| `options` | `{ value: T; label: ReactNode; icon?: ReactNode; disabled?: boolean; title?: string; ariaLabel?: string }[]` | — | `title` — причина недоступности («Сервер допускает до 1080p») |
| `size` | `'sm' \| 'md'` | `'md'` | 32 / 36 |
| `full` | `boolean` | `false` | на всю ширину, пункты равной ширины |

документа) и `mock.js` (переключатель темы, сегменты, ползунки, вкладки; без внешних скриптов). Каждый макет —
`?theme=dark|light`, адаптивен 320…2560, снимки 1440×900 и 390×844 в обеих темах — `mockups/shots/` (60 файлов;
пересъёмка — из `web/`: `node ../backlog/review-1.0.3/mockups/shoot.mjs`).

| Файл | Что показывает |
| --- | --- |
| `settings.html` | окно настроек: дерево, «Звук» и «Видео» без прокрутки (карточки), «Оверлей» с группами и подсветкой якоря, сегменты, ползунок, переключатели, тонкие полосы |
| `home.html` | главная: плита «Новая встреча», вход по коду, избранное с «Закрепить», меню с переключателем «Автоподключение» |
| `prejoin.html` | предвход: две колонки, сегмент доступа, переключатель интеграций, sticky-кнопка; 1280×714 |
| `meeting.html` | встреча: шапка с гарнитурой и отступом Electron, чипы интеграций и мини-плеер справа сверху, виджет музыки, панель-карточка, красная кнопка показа, бейдж чата, закреплённая плитка с «Открепить», вложение в чате |
| `player.html` | полный плеер в панели (площадки, поиск, очередь, зона файлов) и телефонный лист |
| `support.html` | окно поддержки с тремя вкладками и «О программе» |
| `overlay.html` | виджет говорящих в четырёх углах и размерах, всплывашка при старте игры, страница настроек оверлея |
| `share-picker.html` | окно показа: вкладки, миниатюры, Чёткость/Плавность, качество, превью, одна кнопка |
| `mini-overlay.html` | мини-оверлей звонка: компактный и развёрнутый, меню трея |
