# CODEMAP-WEB — карта веб-клиента под «Ревью 1.0.3»

Дата: 21.10.2026. Это карта кода под задачи `TASKS.md` (R11–R56, R65, R70–R76; R34 — только веб-часть). Код при её
составлении не менялся. Пути даны от `web/src`, если не сказано иное. Каждую строку `путь:строка` проверяли по
рабочей копии `/opt/ModernStreamingSystem`. Клиент Windows лежит в `/opt/ModernStreamingSystem.Windows`.

**Правила для всех задач волны**

- **Локали.** Ключ i18n убирают или добавляют сразу во всех восьми файлах `i18n/locales/{ru,en,de,es,fr,it,pt-BR,zh-Hans}.json`.
  Тест `i18n/coverage.test.ts` сравнивает каждый язык с `ru` и падает и на пропущенном ключе, и на лишнем.
  Кириллицу в коде ограничивает храповик `scripts/i18n/check.mjs` (база — `baseline.json`). Если строки вынесены в локали,
  базу перезаписывают командой `--update`.
- **CSS только на токенах.** В `settings.css`, `integrations.css` и `kit.css` нельзя писать hex, `rgb()` и `!important`,
  а размер шрифта задаётся только `--text-*`. Это проверяют `settings/settings-css.test.ts`, `ui/integrations-css.test.ts`
  и `kit/kit.test.tsx`.
- **Слои.** Модальный `Dialog` Base UI должен лежать на слое не ниже 39. Слой меню ставят на `Positioner`, а не на
  попап (`backlog/knowledge/memory/cord-ui-traps.md`, `backlog/CONTEXT.md` → «Грабли интерфейса»).
- **e2e читают русский текст** (`playwright.config.ts`: `locale: 'ru-RU'`). Чаще всего ищут «Новая встреча» (19 спеков),
  «Ваше имя» (17), «В эфире» (13), «Начать встречу» и «Войти во встречу» (около 15).

## Системные решения

### S1. Фокус: модальность ввода (R26, R11, R23, R75, крестики, окна)

Корень и все места — в R26 (раздел D). Решение одно на всё приложение.

1. **`ui/input-modality.ts`** вместо `ui/pointer-focus.ts`. Устанавливается там же, где сейчас `installPointerFocus`:
   `main.tsx:10-13` и `telegram/main.tsx:8,21`.
   - На `pointerdown` (capture) ставит `document.documentElement.dataset.input = 'pointer'`.
   - На `keydown` ставит `'keyboard'`, только если клавиша из набора `Tab`, `ArrowUp/Down/Left/Right`, `Home`, `End`,
     `PageUp`, `PageDown`, `F6` и не зажаты Ctrl, Alt или Meta. Shift разрешён: Shift+Tab и Shift+стрелки — навигация.
   - Не переключают режим: одиночные Shift, Ctrl, Alt, Meta; любые сочетания (микрофон Ctrl+Shift+M, оверлей); Esc,
     Enter, Space, буквы; уход и возврат окна (Alt+Tab, глобальные сочетания Electron).
   - Начальное значение — `'pointer'`.
2. **CSS — одно кольцо.**
   - В `tokens.css`: `:root:not([data-input='keyboard']) { --focus-outline: 0 solid transparent }`.
     Все правила на `var(--focus-outline)` выключаются сами.
   - Литералы перевести на токен: `styles.css:57`, `chess.css:139`, `:586`, `game-polish.css:107`, `:122`,
     `durak.css:30`, `gartic.css:70`, `:1033`, `cinema/cinema.css:306`, `game-people.css:113`.
   - Глобальное правило `styles.css:51-58` переписать на `:where(button, a, input, select, textarea, [tabindex]:not([tabindex='-1'])):focus-visible`.
     Вес `:where()` нулевой, поэтому любой класс его перебивает.
   - Контейнеры кольца не получают никогда: `:where([tabindex='-1'], [role='dialog'], [role='alertdialog'], [role='menu']):focus-visible { outline: none }`.
     Отдельно добавить `outline: none` старому `.modal`.
   - Пункт меню: `.ui-menu__item:focus-visible { outline: none }`. Его показывает `data-highlighted`; в режиме клавиатуры
     можно добавить внутреннее кольцо `box-shadow: inset 0 0 0 2px var(--accent)`.
   - У полей ввода (`.ui-input`, `.settings-search:focus-within`, `.composer:focus-within`) своё выделение рамкой — оставить
     как есть, оно не зависит от режима.
   - `!important` не нужен (его запрещают тесты CSS).
3. **Начальный фокус окон.**
   - `SettingsWindow` (R11): `initialFocus` — заголовок раздела `.settings-content__title` (`tabIndex=-1`) или
     `(type) => type === 'keyboard' ? true : popup`.
   - kit `Dialog`, `Modal`, окно помощи: по умолчанию остаётся крестик, после пункта 2 кольца на нём нет.
4. **Как проверить.** Новый e2e в настоящем Chromium. Для каждого места — окна настроек, kit `Dialog`, «Помощи», меню
   избранного, записи сочетания — пройти два пути:
   - щелчок → Shift → `outline-style: none`;
   - Tab → `solid`.

   Плюс axe. Обновить `e2e/kit.spec.ts:27-32` и `ui/pointer-focus.test.ts`, `docs/frontend.md:111-115`,
   `backlog/knowledge/memory/cord-ui-traps.md`.

Доступность с клавиатуры сохраняется: кто ходит Tab-ом и стрелками, сразу переводит страницу в режим клавиатуры, и кольцо
есть на каждом элементе управления (WCAG 2.4.7).

### S2. Полосы прокрутки (R17, полоса `html` на предвходе R73)

- **Токены** в `tokens.css`, обе темы: `--scrollbar-size: 10px`,
  `--scrollbar-thumb: color-mix(in srgb, var(--text) 22%, transparent)`, `--scrollbar-thumb-hover` (около 38 %).
- **Правило в `styles.css`**, рядом с базой:

  - дорожка, угол и кнопки: `::-webkit-scrollbar-track` и `::-webkit-scrollbar-corner` — `background: transparent`,
