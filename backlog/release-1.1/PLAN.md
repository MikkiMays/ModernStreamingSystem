31.10.2026. Задачи владельца — `TASKS.md` (R143–R159, дословно). Разбор по коду: продукт —
`ANALYSIS-PRODUCT.md`, медиа и платформы — `ANALYSIS-MEDIA.md` (оба — снимок `main` 4667808 /

## 1. Что такое 1.1

Не очередная правка, а релиз продукта: доска во встрече, фон в видео, гибкие кодеки, недавние
встречи, общие настройки между серверами, «звук встречи» отдельной кнопкой. С 1.1.0 у веба, клиента
Windows и Android одна версия (Р-46). Веб выкатывается по мере готовности пакетов, клиент Windows и APK —
выпусками 1.1.x, когда менялся их код.

`services`), не дожидаясь выпуска. Клиент Windows — пуш `main` репы Windows → CI выпуск → зеркало
(`backlog/bin/publish-windows.sh --desktop X.Y.Z`), cordcam — ветка `deploy/cordcam`.

- Каждый пакет: точечные тесты (`vitest run <файлы>`, `-Dtest=…`), `tsc -b` и prettier перед слиянием, CI
  ветки зелёный.

- Полный прогон (vitest всего веба, `verify` ядра, службы) — в конце волны (память «dev-first-test-at-end»).
