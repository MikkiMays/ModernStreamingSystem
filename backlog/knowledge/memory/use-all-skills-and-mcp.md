24.09.2026 владелец [[meet-cord-system]] попросил записать в память навсегда: «о максимальном
использовании всех доступных mcp и скиллов, а также чтобы сам добавлял, я даю на все
разрешение».

- В начале задачи смотреть список скиллов, агентов и MCP и брать всё, что подходит: процессные
  (superpowers: brainstorming, writing-plans, TDD, systematic-debugging,
  verification-before-completion, code review), предметные (frontend-design,
  vercel:react-best-practices, codebase-design), проверочные (Playwright MCP, скилл
  `ModernStreamingSystem/web:verify`), документацию библиотек — через context7.
- Не хватает инструмента — **ставить самому** (плагин, скилл, MCP-сервер), не спрашивая.
  Предпочитать официальные и известные источники: сторонний MCP получает доступ к машине.
- Параллельную работу раздавать агентам с непересекающимися каталогами; сводить результат самому.

**Why:** он хочет, чтобы задачи делались «на 100 %» и видел, что установленные инструменты
простаивают, пока модель делает всё вручную.

**How to apply:** в отчёте по задаче называть, какие скиллы/агенты реально сработали и на чём.
