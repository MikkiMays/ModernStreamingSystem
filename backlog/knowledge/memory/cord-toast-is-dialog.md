# Тост Base UI — `role="dialog"`: «открыто окно?» спрашивать через `modalOpen()`

Факт (31.10.2026, R142): `Toast.Root` Base UI 1.8 рендерится с `role="dialog"` (высокий приоритет —
`alertdialog`). Горячие клавиши встречи молчат, пока открыто окно, и раньше проверяли это
`document.querySelector('[role="dialog"]')` — тост «Ссылка на встречу скопирована» на 5–10 с глушил
клавишу микрофона, пробел и стрелки кинозала, «G» сцены и клавиши покера (CI `cinema-link`
«space pauses…» упал на ветке).

Как применять: «открыто ли окно поверх встречи» — только `modalOpen()` / `MODAL_SELECTOR` из
`web/src/ui/modal.ts` (исключает `.ui-toast`); новый обработчик клавиш — через него же.
