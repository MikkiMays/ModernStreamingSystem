# cord-windows-bridge

The native client is the separate ModernStreamingSystem.Windows repository. Inspect it only when the task covers it. Check WebView2 navigation and origin restrictions, message validation, persistent profile and session behavior, deep-link parsing and server-scoped state. Preserve web and server compatibility. Windows compilation, installer signing and runtime acceptance require a Windows environment; never report them as passed from Linux.
